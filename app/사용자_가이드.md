# 📘 copycopyWA 오답노트 관리 프로그램 사용자 가이드

오답노트 관리 프로그램 **copycopyWA**에 오신 것을 환영합니다!
본 프로그램은 학생별 오답 문제 이미지를 자동으로 취합하여 지정된 PDF 템플릿 양식에 맞춰 깔끔한 오답노트 PDF 문서로 생성해 주는 프로그램입니다.

---

## 🚀 1. 최초 실행 설정 가이드 (온보딩 2단계)

프로그램을 처음 실행하면 `prevConfig.json` 파일이 없는 상태를 감지하여 **자동으로 초기 설정 단계(2단계)**가 시작됩니다.

### 1️⃣ 1단계: 경로 설정 (`PathDialog`)
* **템플릿 경로(PDF)**: 오답노트 배경으로 사용되는 템플릿 PDF 파일 경로 (기본값: 프로젝트 내 `template.pdf`)
* **원본 폴더**: 오답 문제 이미지 파일들이 들어있는 폴더 경로
* **대상 폴더**: 생성된 오답노트 PDF 파일이 결과물로 저장될 폴더 경로

### 2️⃣ 2단계: PDF 이미지 및 여백 설정 (`DialogPdfConfig`)
* **이미지 가로/세로 (target_w / target_h)**: PDF 페이지에 배치될 오답 문제 이미지의 크기
* **좌우/상하 여백 (h_margin / v_margin)**: PDF 종이 테두리와 이미지 간의 공간 여백
* **이미지 위치 미세 조정 (x-offset / y-offset)**: 템플릿의 양식 라인에 맞춰 이미지를 상하좌우로 미세 이동
* **미리보기**: 우측 그래픽 뷰에서 설정값이 실제 PDF 상에 배치되는 모양을 실시간으로 확인 가능

## 📑 2. 주요 기능 사용법

### 1) 학생 데이터 등록 및 수정
* **학생 추가**: `[학생 추가]` 버튼을 눌러 테이블에 새로운 입력 행을 만듭니다.
* **데이터 입력**:
  * **이름**: 학생 이름 (예: `홍길동`)
  * **오답노트 제목**: 오답노트 표지/제목 (예: `3월 모의고사 오답노트`)
  * **오답노트 번호**: 캡처된 오답 문제 번호 (예: `1, 3, 5, 7, 10` 또는 범위 입력 `5-10`)
* **저장**: `[학생 저장]` 버튼을 누르면 설정된 정보가 `prevConfig.json`에 저장됩니다.

### 2) 엑셀 내보내기 / 불러오기 (학생 데이터 관리)
* **학생데이터 내보내기 (`Export`)**: 입력된 학생 정보를 엑셀(`.xlsx`) 파일로 내보냅니다.
* **학생데이터 불러오기 (`Import`)**: 기존 엑셀 파일에서 학생 목록을 대량으로 가져옵니다.

### 3) 오답노트 PDF 생성
1. PDF를 출력할 학생들의 맨 앞 **체크박스**를 선택합니다 (전체 선택 가능).
2. `[오답노트 PDF 저장]` 버튼을 클릭합니다.
3. 원본 폴더에서 해당 번호의 이미지를 찾아 PDF 템플릿과 결합한 후, 대상 폴더에 학생별 PDF 파일이 자동으로 생성됩니다.

## 🛠️ 3. 설정 변경 및 환경설정 관리

초기 설정 이후에도 언제든지 상단 메뉴바를 통해 설정을 변경할 수 있습니다.

* **상단 메뉴 > [설정] > [경로 설정 열기]**: 원본/대상 폴더 및 PDF 템플릿 파일 변경
* **상단 메뉴 > [설정] > [PDF 설정]**: PDF 이미지 크기 및 여백 미세 조정
* **상단 메뉴 > [정보] > [버전확인]**: 현재 프로그램 버전 확인

## ❓ FAQ 및 문제 해결

* **Q. PDF 생성이 안 되거나 이미지가 안 나와요.**
  * 원본 폴더 경로가 올바른지 확인해 주세요.
  * 오답 문제 이미지 파일명이 학생 오답노트 번호 규칙과 일치하는지 확인해 주세요.
* **Q. 설정값을 초기화하고 싶어요.**
  * 프로그램 종료 후 폴더 내 `prevConfig.json` 파일을 삭제하고 프로그램을 재실행하면 최초 실행 모드로 다시 작동합니다.
